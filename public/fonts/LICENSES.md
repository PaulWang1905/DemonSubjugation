# Bundled pixel fonts

The player's "Pixel ·" text choices use these fonts, converted by
`scripts/fonts/build_fonts.py` into the device's 16-pixel HZK16 / ASC16
layout (`cjk16.bin`: GB2312 characters, 16×16; `latin16.bin`: ASCII, 8×16).
